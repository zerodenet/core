# Physical owner registration

`CarrierOwner::registration()` is non-authorizing weak observation of the same
physical owner. Numeric instance equality does not match a foreign owner/grant.
Snapshots contain only currently retained slots (bounded by the explicit limit),
actual join witnesses and original acquisition/native-close fault Arcs; native
getters run after all enclosing carrier locks are released. Unknown disposition,
returned close fault and pending synchronous I/O remain distinct facts.

Snapshot count zero, expired Weak, caller/driver Drop and join do not issue
physical generation closure. `CarrierOwnerClosed` is privately issued only after
that original owner's explicit shutdown observes every original slot's real
join/native close. Its small completion receipt can survive owner release without
retaining sockets, scope or runtime. It covers physical generation closure;
external protocol/business users remain a separate obligation.

No declaration, native grant, host publication or Business permission is created
by registration. `registration.bind_declared` binds a cold, unattempted owner once to a full
canonical `ControlledOutboundStream` description and actual weak scope identity.
Only an identical description and same registrar can repeat it before start;
changed facts, started/attempted or stopping owners are rejected. Bound native
prepare checks the full endpoint/binding/demand and registration state. Bound
driver adoption checks the original registrar before invoking its build closure.
Unbound library owners retain their original Service-only behavior and are not
qualified resource registrations. The host must independently check its actual
declaration ordinal, instance, cap, scope and installed lifecycle before accepting
the opaque binding as coverage. Physical completion still excludes transferred
business users, whose actual owner/handler join remains separate. The existing Service-only
Business rejection is unchanged.

The first successful binding also freezes the original host revocation token.
Idempotent binding requires the same Arc identity and never replaces it with
another token. A protocol prebinding a foreign fence cannot impersonate the
actual host registration even if its description and scope match. Revocation rejects new
reservation/acquisition/adoption, interrupts the existing prepared open, and is
selected inside the same registered aggregate task (ready original task results
keep priority). No cancellation worker is created and no permit is refunded by
body exit: the actual scope join and original native close remain required.
