# Physical owner registration

`CarrierOwner::registration()` is non-authorizing weak observation of the same
physical owner. Numeric instance equality does not match a foreign owner/grant.
Snapshots contain only currently retained slots (bounded by the explicit limit),
actual join witnesses and original acquisition/native-close fault Arcs; native
getters run after all enclosing carrier locks are released. Unknown disposition,
returned close fault and pending synchronous I/O remain distinct facts.

Snapshot count zero, expired Weak, caller/driver Drop and join do not issue
physical generation closure. `CarrierOwnerClosed` is privately issued only after
that original owner's explicit shutdown observes every original slot's real
join/native close. Its small completion receipt can survive owner release without
retaining sockets, scope or runtime. It covers physical generation closure;
external protocol/business users remain a separate obligation.

No declaration, native grant, host publication or Business permission is created
by registration. Binding the same owner to the canonical declaration and actual
scope, and enforcing that binding at native acquisition and driver registration,
remain necessary before host resource qualification. The existing Service-only
Business rejection is unchanged.
