## 冲突与过渡优先级

1. 本次授权限定为 PR00：只保存方案及检查，不实施后续功能，不修改 AGENTS.md、运行代码、依赖、版本、锁文件政策、发布、CI 门禁或生产配置。
2. 用户最后确认的单实例与清理规则优先：同一资源先停旧并确认任务/I/O/设备释放，再串行启动替代实例；候选清理未确认，禁止启动同资源旧实例恢复。1 CPU/1 GiB 不采用双完整内核或长期退役池排空。
3. 同一主题以 [rust-contracts.md](rust-contracts.md) 的详细签名、[lifecycle.md](lifecycle.md) 的状态表及已确认决策为准。M1 概览中“traits/core 补齐标准”不代表把 Tokio trait 放入 no_std crate；运行契约在 platform-tokio::contract。Factory.build 同步创建无 I/O 的实例及生命周期所有者，随后 start 才执行有副作用启动；概览不得放宽此顺序。
4. 现有 AGENTS.md 的 capability/prepared operation、先预绑定新端口、active guard 保留等是迁移前约束。PR00 不提前移除；对应实现 PR 同步修改拥有方、调用方、工程规则、兼容性账本和回归。尤其 PR07B 不能用旧规则恢复新旧同资源并行。
5. 接口迁移允许短期 facade，每条实际业务路径只保留一个生产执行者。兼容桥按任务卡删除，不保留两套长期框架。设计不证明现有实现已满足目标，也不把既有功能记为重构成果。

未变化实例复用；普通规则/组更新保留既有连接；重建只中断依赖连接；撤权终止关联会话；限速立即作用于后续流量。配置修订与运行健康分离，失败恢复隔离受影响组件并保留健康业务及控制面。停止立即取消业务，但任务/I/O/系统状态及必要本地可靠状态收尾得到确认后才正常退出。

## 完整设计正文

<!-- source-section: 00 -->
Zero 的目标架构以稳定的组件职责和标准契约组织整个内核。协议、DNS、路由、网络服务和控制适配器分别实现职责，运行宿主负责装配与配置事务。Rust 的类型、所有权、借用和异步取消规则用于表达这些边界。

设计范围覆盖所有 crates、protocols、应用入口及客户端和面板的兼容边界。实施版本已确定为 v0.0.3，集成分支为 develop，通过云端短期工作分支和 PR 分阶段完成。新增协议是标准的验收场景之一，不是重新划分内核的出发点。本文定义整体目标、标准契约、迁移任务和验收边界；本轮只完善方案，不启动实现。

核心决策：

- 用独立的共享契约连接组件，不让协议依赖 proxy 私有执行类型。

- 由组件管理内部协议状态和资源，由宿主管理生命周期范围、依赖与发布顺序。

- 保留现有配置和外部控制面，以兼容适配器隔离内部 Rust 接口迁移。

- 泛型与关联类型用于具体实现，类型擦除集中在异构组件和通道边界。

- 先建立行为基线，再逐边界替换。编译通过、字段未变或 API 版本未变都不能单独证明兼容。

版本与集成分支已确定：本次整体重构属于 v0.0.3，所有任务通过 PR 合入 GitHub 仓库 zerodenet/core 的 develop。单个 PR 完成不代表整体重构完成；以下目标全部具备验收证据后，才可关闭整体任务。

| 目标 | 最终交付 | 完成证据 |
| --- | --- | --- |
| G0 实施基线 | 版本化方案、任务卡、基线提交与兼容样本清单 | PR00 与 PR01；云端新检出可找到完整标准 |
| G1 组件标准 | 入站、出站、通道、网络、生命周期与错误契约 | 公共契约不依赖 proxy 私有类型，静态与动态边界测试 |
| G2 实例与配置 | 配置一次转换、预构建角色、registry 与实例管理职责明确 | 连接路径不再重复解释全局配置，最小 feature 验证 |
| G3 出站与 UDP | Stream 和 Datagram 标准执行、链路与协议内部复用 | 各现有协议互通，UDP 正常路径移除 Any 加 handler 猜测 |
| G4 接入 | 普通流、UDP、MUX、QUIC、Control 与 fallback 标准交付 | 慢握手并发、响应、身份、独立关闭和取消测试 |
| G5 宿主与事务 | 公共 RuntimeHost、统一应用确认与资源生命周期 | 准备失败、切换失败、回滚失败、幂等更新和退出确认 |

| G7 Packet 与端点 | 共享资源、原生回程、公共转换和 TUN 拥有关系 | Packet 模式矩阵、源地址、MTU、交接语义及平台 E2E |
| G8 控制与观测 | 稳定 API 投影、事实与采样边界、明确内外层计量 | V1 样本、ACK、事件重放、流量结算及 FFI 公共面验证 |

| G10 收尾 | 旧桥接删除、规则和文档一致、最终验证 | 全量 CI、最小 feature、互通、平台与性能对比报告 |

范围不包含新增协议、升级协议上游基线、客户端 UI 重做、面板业务调整、生产部署或自动发布。发现确实无法兼容的变更时，记录具体消费者、替代路径与迁移成本，不能把适配责任静默转给客户端和面板。
