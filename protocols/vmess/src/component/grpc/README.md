# VMess gRPC carrier ownership

The ordinary production adapter selects `Options::from_node_options_refs` for
non-MUX Datagram flows with supported prepared TLS, including host-owned CA
snapshots and domain nodes backed by the configured native Node DNS provider.
External ECH and unqualified DNS styles remain compatible. This recipe declares
`ControlledNodeStream` and only the executable Datagram role. Default-dial relay
chains with ordinary, task/pool/dependency-free Stream prefixes use the same
actual Datagram owner; the host prepares those protocol handshakes inline over
the one original TCP body before TLS/gRPC. Actual prefix generation edges drive
confirmed consumer retirement before replacement. TCP, probes and unqualified
relay prefixes keep their existing compatibility callers.
It uses the same actual adapter runtime's weak, secret-free identity index,
checks complete recipe equality, and reclaims a prior recipe only after that
original owner's native/users close receipt. The host still confirms the whole
component graph before building or starting a successor.

Controlled acquisition uses `UpstreamOpener::acquire_controlled_stream`; the
redundant public async preparation method is removed. Native/DNS preparation
stays inside the host, while a hosted pool prefix returns its actual StreamLoan.
The consumer installs that logical controller before later framing or handshakes
and retains its own original H2 scope. Its borrowed slot completion does not
claim the donor's native close; host generation edges must also retire the
actual donor scope and original provider. Shared non-I/O dependencies such as
TCP2022 replay maintenance may remain inline on the final owner's real socket.
Ordinary unqualified MUX/Mieru registration is still closed.

Every production flow uses a fresh real H2 client and the same single scoped
driver as the library implementation. Unique transferred Datagram custody is
claimed before native preparation; there is no invented TCP caller task. TX/RX
must return before releasing that logical carrier. Shutdown then consumes its
actual driver exit and original native close, without requiring peer EOF or
using view return as native evidence. Live, retiring and Unknown originals
remain charged. A changed network cannot acquire while old originals/users
remain; failed or interrupted cleanup retains the same controls and sources.
The current production ceiling is the existing host Datagram ceiling of 4096,
with no eager task/socket allocation; configurable budgets remain separate work.

The following describes the explicit library Stream recipe, whose fixed-binding
and Service-only fixtures do not qualify additional production styles.

`Options::from_options_refs_at(..., NonZeroUsize, &actual_runtime)` binds the
adapter's actual carrier-admission state. It declares a real BackgroundCarrier,
an optional explicitly bounded File grant, and N actual scoped tasks for N
pending/live/retiring physical carriers. Each connect creates a fresh real H2
Client and one logical stream, with the original keepalive and read/write
futures polled inside that one registered driver. No GrpcPool or client cache is
created; legacy Client multiplexing APIs and production selection stay intact.

This first library admits one complete transport/credential/budget recipe per
actual Runtime. Complete equality and a checked opaque recipe nonce prevent
cold identity aliasing. All ordinary legacy TCP/UDP/relay gRPC transport entries
use the same real Runtime state before their own I/O. Legacy exposure is sticky
negative evidence, never a close receipt. A native claim refuses it; legacy
openers refuse a claimed state. Unsupported old clients cannot be adopted,
reset, or declared drained by Drop, AbortHandle, or a zero user count. A second
profile or owner generation requires future confirmed replacement work.

Build remains cold. Start claims that exact state, uses the existing CaOwner
and actual ResourceAccess File snapshot, then starts its controlled carrier
owner and admission. There are no new size/task/default schema values. Relative
CA paths retain the original source-dir base; connect never reopens the CA.

Reserve persists the opaque same-slot adoption before native preparation or
await. The actual upstream provider installs the original control, and the
original TLS/H2 driver retains its tag through preparation and the single
spawn_tracked transaction. Drop/cancel only request retirement. Physical quota
is reusable only after the real Scope consumes the exact driver exit and the
original native control issues its matching private close receipt. Unknown
acquisition retains finite capacity and original source. Reaped complete
metadata is reclaimed, not kept as an unbounded per-connect history; shutdown
reports the actual resources still owned at shutdown. Scope task IDs are not
reported twice by protocol cleanup. Returned I/O preserves the same actual
scoped failure Arc when the physical driver fails.

Each library demand supplies an explicit absolute deadline; missing deadlines
are rejected before I/O instead of inventing a new timer or resetting a prior
request budget. Request Session identity is forwarded unchanged. The supplied library
NativeCarrierOpener only supports literal/empty-prefix Service carriers and
rejects real Business Some(SessionId) before native I/O. The library success
fixtures therefore prove Service behavior only. The production Datagram recipe above has its actual Business provider and
host replacement path, including qualified native DNS, CA snapshots and
ordinary Stream relay prefixes. System/detour DNS, external ECH, resourceful or
mixed relay prefixes and ordinary VMess MUX retain their separate migration
gates; the public ordinary Options continues to reject gRPC/CA instead of
silently discarding resource ownership.

Hosted Auxiliary exits are delivered into the same bounded carrier Record. User
failure reads and actual owner cleanup first retain the original TaskJoined and
its unchanged failure Arc, then mark local acceptance on that witness. The host
must still acknowledge its actual publication receipt. Acknowledgement does not
close the native carrier or refund its physical slot. Actual no-user cleanup uses
that same Record; there is no Auxiliary history map or second task manager.
Ordinary scopes retain their existing task/source behavior. Service-only native
provider restrictions and all production resourceful eligibility gates remain.

The ordinary Proxy catalog now qualifies a literal VMess MUX root-prefix subset
with its real shared-pool Stream loan and original parent registration. The
compatibility UDP codec delegates to the same native physical pool; the prefix
advertises Stream only. Non-root/nested combinations and other ordinary MUX
styles retain their existing admission gates. Pool limits are on demand and
optional; no second native/legacy driver is installed for an admitted node.
